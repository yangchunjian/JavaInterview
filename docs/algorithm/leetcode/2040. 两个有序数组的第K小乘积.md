## 题目

给你两个 **从小到大排好序** 且下标从 **0** 开始的整数数组 `nums1` 和 `nums2` 以及一个整数 `k`，请你返回第 `k`（从 **1** 开始编号）小的 `nums1[i] * nums2[j]` 的乘积，其中 `0 <= i < nums1.length` 且 `0 <= j < nums2.length`。

### 示例 1

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums1 = [2,5], nums2 = [3,4], k = 2` |
| **输出** | `8` |

**解释：** 第 2 小的乘积计算如下：

- `nums1[0] * nums2[0] = 2 * 3 = 6`
- `nums1[0] * nums2[1] = 2 * 4 = 8`

第 2 小的乘积为 `8`。

### 示例 2

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums1 = [-4,-2,0,3], nums2 = [2,4], k = 6` |
| **输出** | `0` |

**解释：** 第 6 小的乘积计算如下：

- `nums1[0] * nums2[1] = (-4) * 4 = -16`
- `nums1[0] * nums2[0] = (-4) * 2 = -8`
- `nums1[1] * nums2[1] = (-2) * 4 = -8`
- `nums1[1] * nums2[0] = (-2) * 2 = -4`
- `nums1[2] * nums2[0] = 0 * 2 = 0`
- `nums1[2] * nums2[1] = 0 * 4 = 0`

第 6 小的乘积为 `0`。

### 示例 3

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums1 = [-2,-1,0,1,2], nums2 = [-3,-1,2,4,5], k = 3` |
| **输出** | `-6` |

**解释：** 第 3 小的乘积计算如下：

- `nums1[0] * nums2[4] = (-2) * 5 = -10`
- `nums1[0] * nums2[3] = (-2) * 4 = -8`
- `nums1[4] * nums2[0] = 2 * (-3) = -6`

第 3 小的乘积为 `-6`。

### 提示

- `1 <= nums1.length, nums2.length <= 5 * 10^4`
- `-10^5 <= nums1[i], nums2[j] <= 10^5`
- `1 <= k <= nums1.length * nums2.length`
- `nums1` 和 `nums2` 都是从小到大排好序的。

## 思路

两个数组长度最大约 5 万，全部乘积最多约 25 亿个，不能显式生成后再排序。观察可知：若某个候选值 `x` 满足「乘积小于等于 `x` 的个数不少于 `k`」，则第 `k` 小乘积一定不超过 `x`；否则一定严格大于 `x`。乘积的取值范围在负 1e10 到正 1e10 之间，对 `x` 做二分即可定位答案。

统计「小于等于 `mid` 的乘积个数」时，枚举 `nums1` 中的每个数 `a`，在有序的 `nums2` 上二分。需要按 `a` 的正负分开处理，因为 `nums2` 递增时，乘积的单调方向不同。

当 `a` 为正数时，乘积随 `nums2[j]` 递增。在 `nums2` 中找最大的 `j`，使得 `a * nums2[j]` 不超过 `mid`，则下标 `0` 到该位置之前共有这么多个合法 `j`。

当 `a` 为负数时，乘积随 `nums2[j]` 递减。在 `nums2` 中找最小的 `j`，使得 `a * nums2[j]` 不超过 `mid`，则从该下标一直到数组末尾都合法。

当 `a` 为 0 时：若 `mid` 大于等于 0，则与任意 `nums2[j]` 的乘积都是 0，全部计入；否则一个都不计入。

比较乘积时用 `long`，避免 `int` 溢出。二分乘积值大约 34 轮，每轮对 `nums1` 每个元素在 `nums2` 上再做一次对数查找。若 `nums1` 更长，可交换两个数组，使外层枚举更短。总体复杂度可以接受。

## 解法

```java
class Solution {
    public long kthSmallestProduct(int[] nums1, int[] nums2, long k) {
        if (nums1.length > nums2.length) {
            return kthSmallestProduct(nums2, nums1, k);
        }
        long left = -10000000000L;
        long right = 10000000000L;
        while (left < right) {
            long mid = left + (right - left) / 2;
            if (countNotGreater(nums1, nums2, mid) >= k) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }

    private long countNotGreater(int[] nums1, int[] nums2, long mid) {
        long cnt = 0;
        int n = nums2.length;
        for (int a : nums1) {
            if (a > 0) {
                int l = 0;
                int r = n;
                while (l < r) {
                    int m = (l + r) >>> 1;
                    if ((long) a * nums2[m] <= mid) {
                        l = m + 1;
                    } else {
                        r = m;
                    }
                }
                cnt += l;
            } else if (a < 0) {
                int l = 0;
                int r = n;
                while (l < r) {
                    int m = (l + r) >>> 1;
                    if ((long) a * nums2[m] <= mid) {
                        r = m;
                    } else {
                        l = m + 1;
                    }
                }
                cnt += n - l;
            } else if (mid >= 0) {
                cnt += n;
            }
        }
        return cnt;
    }
}
```

## 总结

- 第 `k` 小乘积可用「对乘积值二分加计数」求解，不必枚举全部配对。
- 计数时按乘数正、负、零三种情况，在另一有序数组上二分，注意负数会翻转单调性。
- 乘积比较必须用 `long`；答案范围按两端极值取负 1e10 到正 1e10。
- 外层枚举较短数组可以降低常数。
