## 题目

一位老师正在出一场由 **n** 道判断题构成的考试，每道题的答案为 **true**（用 `T` 表示）或者 **false**（用 `F` 表示）。老师想增加学生对自己做出答案的不确定性，方法是 **最大化** 有 **连续相同** 结果的题数（也就是连续出现 `T` 或者连续出现 `F`）。

给你一个字符串 `answerKey`，其中 `answerKey[i]` 是第 **i** 个问题的正确结果。除此以外，还给你一个整数 `k`，表示你能进行以下操作的最多次数：

- 每次操作中，将问题的正确答案改为 `T` 或者 `F`（也就是将 `answerKey[i]` 改为 `T` 或者 `F`）。

请你返回在不超过 `k` 次操作的情况下，**最大** 连续 `T` 或者 `F` 的数目。

### 示例 1

| 项目 | 内容 |
| --- | --- |
| **输入** | `answerKey = "TTFF"`, `k = 2` |
| **输出** | `4` |
| **解释** | 可以将两个 `F` 都变为 `T`，得到 `answerKey = "TTTT"`，共有四个连续的 `T`。 |

### 示例 2

| 项目 | 内容 |
| --- | --- |
| **输入** | `answerKey = "TFFT"`, `k = 1` |
| **输出** | `3` |
| **解释** | 可以将最前面的 `T` 换成 `F`，得到 `answerKey = "FFFT"`；或者将第二个 `T` 换成 `F`，得到 `answerKey = "TFFF"`。两种情况下，都有三个连续的 `F`。 |

### 示例 3

| 项目 | 内容 |
| --- | --- |
| **输入** | `answerKey = "TTFTTFTT"`, `k = 1` |
| **输出** | `5` |
| **解释** | 可以将第一个 `F` 换成 `T`，得到 `answerKey = "TTTTTFTT"`；或者将第二个 `F` 换成 `T`，得到 `answerKey = "TTFTTTTT"`。两种情况下，都有五个连续的 `T`。 |

### 提示

- `n == answerKey.length`
- `1 <= n <= 5 * 10^4`
- `answerKey[i]` 要么是 `T`，要么是 `F`
- `1 <= k <= n`

## 思路

本题等价于：在最多修改 `k` 个字符的前提下，求字符串中最长的一段，使得该段内所有字符相同（全为 `T` 或全为 `F`）。

定义辅助函数：固定目标字符为 `T` 或 `F` 中的一种，用滑动窗口维护一段子串。窗口内「非目标字符」的个数记为需要修改的次数；当该次数超过 `k` 时，右移左边界缩小窗口。遍历结束后，以当前左边界到字符串末尾的长度，即为「最多改 `k` 次、全变成该目标字符」时的最长连续长度。

分别对目标字符 `T` 和 `F` 各算一次，取两次结果的最大值即为答案。时间复杂度与字符串长度成正比，额外空间为常数级。

## 解法

```java
class Solution {
    public int maxConsecutiveAnswers(String answerKey, int k) {
        int ans=0;
        char[]c=answerKey.toCharArray();
        int n=c.length,j=0,t=0,f=0;
        for(int i=0;i<n;i++) {
        	if(c[i]=='T')t++;
        	else if(c[i]=='F')f++;
        	while(t>k&&f>k) {
        		if(c[j]=='T')t--;
        		else if(c[j]=='F')f--;
        		j++;
        	}
        	ans=Math.max(ans, i-j+1);
        }
        return ans;
    }
}
```

## 总结

- 滑动窗口：窗口内「与目标字符不同」的个数不超过 `k` 时窗口合法。
- 分别枚举目标为 `T` 和 `F`，取最长窗口长度的最大值。
- 与「最多将 k 个字符替换后，最长全相同子串」同类，可类比力扣 424、1004 等题。
