## 题目

给你一个下标从 **0** 开始且长度为 **n** 的整数数组 `nums`。**分割**数组 `nums` 的方案数定义为符合以下两个条件的 **pivot** 数目：

- `1 <= pivot < n`
- `nums[0] + nums[1] + ... + nums[pivot - 1] == nums[pivot] + nums[pivot + 1] + ... + nums[n - 1]`

同时给你一个整数 `k`。你可以将 `nums` 中 **一个** 元素变为 `k`，或 **不改变** 数组。

请你返回在 **至多** 改变一个元素的前提下，**最多** 有多少种方法 **分割** `nums` 使得上述两个条件都满足。

### 示例 1

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums = [2,-1,2]`, `k = 3` |
| **输出** | `1` |
| **解释** | 最优方案是将 `nums[0]` 改为 `k`，数组变为 `[3,-1,2]`。当 `pivot = 2` 时，分割为 `[3,-1 \| 2]`，左侧和 `3 + (-1) = 2` 等于右侧和 `2`，共 1 种分割方式。 |

### 示例 2

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums = [0,0,0]`, `k = 1` |
| **输出** | `2` |
| **解释** | 最优方案是不改动数组。`pivot = 1` 时分割为 `[0 \| 0,0]`；`pivot = 2` 时分割为 `[0,0 \| 0]`，共 2 种分割方式。 |

### 示例 3

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums = [22,4,-25,-20,-15,15,-16,7,19,-10,0,-13,-14]`, `k = -33` |
| **输出** | `4` |
| **解释** | 最优方案是将 `nums[2]` 改为 `k`，数组变为 `[22,4,-33,-20,-15,15,-16,7,19,-10,0,-13,-14]`，共有 4 种合法分割方式。 |

### 提示

- `n == nums.length`
- `2 <= n <= 10^5`
- `-10^5 <= k, nums[i] <= 10^5`

## 思路

用前缀和数组 `s` 表示：`s[i]` 为 `nums[0]` 到 `nums[i]` 的和（含两端）。数组总和为 `s[n-1]`。

**不修改数组时**：左右两侧和相等，等价于总和为偶数，且存在 pivot 使得左侧前缀和等于总和的一半。预处理时，用哈希表 `right` 统计每个「前缀和」在 pivot 左侧（不含 pivot 位置元素）出现的次数；若 `s[n-1]` 为偶数，则初始答案为 `right` 中键为 `s[n-1] 除以 2` 的计数。

**修改 `nums[i]` 为 `k` 时**：总和变化量为 `d = k - nums[i]`。枚举每个位置 `i`：

- 修改发生在 `i` 左侧时，左侧前缀和不变，合法 pivot 要求左侧和等于新总和的一半，即 `s[i] = (s[n-1] + d) 除以 2`（需新总和为偶数）。
- 修改发生在 `i` 及右侧时，右侧各前缀和均增加 `d`，合法 pivot 要求 `s[i] = (s[n-1] - d) 除以 2`（同样需新总和为偶数）。

维护两个哈希表：`left` 记录当前位置左侧各前缀和出现次数，`right` 记录右侧各前缀和出现次数。对每个 `i`，若 `(s[n-1] + d)` 为偶数，则候选方案数为 `left` 中目标值计数加上 `right` 中目标值计数，与当前答案取较大值。然后将 `s[i]` 从 `right` 移入 `left`（左侧扩大、右侧缩小）。

时间复杂度 O(n)，空间复杂度 O(n)。

## 解法

```java
class Solution {
    public int waysToPartition(int[] nums, int k) {
        int n = nums.length;
        int[] s = new int[n];
        s[0] = nums[0];
        Map<Integer, Integer> right = new HashMap<>();
        for (int i = 0; i < n - 1; ++i) {
            right.merge(s[i], 1, Integer::sum);
            s[i + 1] = s[i] + nums[i + 1];
        }
        int ans = 0;
        if (s[n - 1] % 2 == 0) {
            ans = right.getOrDefault(s[n - 1] / 2, 0);
        }
        Map<Integer, Integer> left = new HashMap<>();
        for (int i = 0; i < n; ++i) {
            int d = k - nums[i];
            if ((s[n - 1] + d) % 2 == 0) {
                int t = left.getOrDefault((s[n - 1] + d) / 2, 0)
                    + right.getOrDefault((s[n - 1] - d) / 2, 0);
                ans = Math.max(ans, t);
            }
            left.merge(s[i], 1, Integer::sum);
            right.merge(s[i], -1, Integer::sum);
        }
        return ans;
    }
}
```

## 总结

- 分割条件等价于：存在 pivot，使得左侧前缀和等于右侧和，即左侧前缀和等于总和的一半。
- 不修改时直接统计；修改时枚举修改位置，用左右哈希表分别统计满足条件的 pivot 个数。
- 核心技巧：前缀和 + 哈希表计数，一次遍历维护左右两侧的前缀和频次。
