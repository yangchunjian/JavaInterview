## 题目

给你三个整数数组 `nums1`、`nums2` 和 `nums3`，请你构造并返回一个**元素各不相同的**数组，且由**至少**在**两个**数组中出现的所有值组成。数组中的元素可以按**任意**顺序排列。

### 示例 1

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums1 = [1,1,3,2]`, `nums2 = [2,3]`, `nums3 = [3]` |
| **输出** | `[3,2]` |
| **解释** | 至少在两个数组中出现的所有值为：3 在全部三个数组中都出现过；2 在数组 `nums1` 和 `nums2` 中出现过。 |

### 示例 2

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums1 = [3,1]`, `nums2 = [2,3]`, `nums3 = [1,2]` |
| **输出** | `[2,3,1]` |
| **解释** | 至少在两个数组中出现的所有值为：2 在 `nums2` 和 `nums3` 中出现过；3 在 `nums1` 和 `nums2` 中出现过；1 在 `nums1` 和 `nums3` 中出现过。 |

### 示例 3

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums1 = [1,2,2]`, `nums2 = [4,3,3]`, `nums3 = [5]` |
| **输出** | `[]` |
| **解释** | 不存在至少在两个数组中出现的值。 |

### 提示

- `1 <= nums1.length, nums2.length, nums3.length <= 100`
- `1 <= nums1[i], nums2[j], nums3[k] <= 100`

## 思路

元素取值范围固定在 1 到 100，可以用长度为 101 的数组做统计，无需哈希表。

**核心问题**：同一个数组里重复出现的数字只应算作「在该数组中出现一次」。例如 `nums1 = [1,1,3,2]` 时，值 1 只能为 `nums1` 贡献 1 次出现记录。

**方法一：位掩码（推荐）**

- 准备 `int[] mask`，下标 `v` 表示值 `v` 在哪些数组中出现过。
- 遍历 `nums1`：对每个出现的值 `v`，执行 `mask[v] |= 1`（标记第 1 个数组）。
- 遍历 `nums2`：对每个出现的值 `v`，执行 `mask[v] |= 2`（标记第 2 个数组）。
- 遍历 `nums3`：对每个出现的值 `v`，执行 `mask[v] |= 4`（标记第 3 个数组）。
- 同一数组内重复元素多次执行按位或，结果不变，天然去重。
- 最后枚举 `v` 从 1 到 100：若 `Integer.bitCount(mask[v])` 大于等于 2，说明该值至少在两个数组中出现，加入答案。

**方法二：频次计数**

- 准备 `int[] freq`，对每个数组单独用 `boolean[] seen` 记录本数组已处理过的值。
- 若 `seen[v]` 为 false，则置为 true 并令 `freq[v]` 加 1。
- 枚举 1 到 100，将 `freq[v]` 大于等于 2 的值加入结果。

两种方法时间复杂度均为 O(n1 + n2 + n3)，额外空间 O(1)（常数 101）。

## 解法

```java
class Solution {
    public List<Integer> twoOutOfThree(int[] nums1, int[] nums2, int[] nums3) {
        int[] mask = new int[101];
        for (int x : nums1) {
            mask[x] |= 1;
        }
        for (int x : nums2) {
            mask[x] |= 2;
        }
        for (int x : nums3) {
            mask[x] |= 4;
        }
        List<Integer> ans = new ArrayList<>();
        for (int v = 1; v <= 100; v++) {
            if (Integer.bitCount(mask[v]) >= 2) {
                ans.add(v);
            }
        }
        return ans;
    }
}
```

## 总结

- 元素范围 1 到 100，用固定长度数组统计即可，不必用哈希集合。
- 同一数组内要去重：位掩码按数组分别置位，或每轮配合 `seen` 数组只计数一次。
- 判断「至少在两个数组中出现」：位掩码看置位个数，或频次数组看计数是否大于等于 2。
