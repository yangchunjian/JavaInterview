## 题目

给你一个字符串 `s`，由 `n` 个字符组成，每个字符不是 `'X'` 就是 `'O'`。

**一次操作**定义为：从 `s` 中选出 **三个连续字符**，并将选中的每个字符都转换为 `'O'`。注意，若某字符已是 `'O'`，则保持 **不变**。

请你返回将 `s` 中 **所有** 字符均转换为 `'O'` 需要执行的 **最少** 操作次数。

### 示例 1

| 项目 | 内容 |
| --- | --- |
| **输入** | `s = "XXX"` |
| **输出** | `1` |
| **解释** | `XXX` 变为 `OOO`：一次操作选中全部 3 个字符并转为 `'O'`。 |

### 示例 2

| 项目 | 内容 |
| --- | --- |
| **输入** | `s = "XXOX"` |
| **输出** | `2` |
| **解释** | 第一次操作选中前 3 个字符 `XXO`，得到 `OOOX`；第二次操作选中后 3 个字符 `OOX`，得到 `OOOO`。 |

### 示例 3

| 项目 | 内容 |
| --- | --- |
| **输入** | `s = "OOOO"` |
| **输出** | `0` |
| **解释** | 字符串中不存在需要转换的 `'X'`。 |

### 提示

- `3 <= s.length <= 1000`
- `s[i]` 为 `'X'` 或 `'O'`

## 思路

从左到右扫描字符串，采用 **贪心** 策略：

- 当前字符为 `'O'` 时，无需操作，下标前进 1 位。
- 当前字符为 `'X'` 时，必须在本轮操作中将其变为 `'O'`。一次操作固定覆盖 **连续三个** 位置，因此从当前下标起向后三格内的所有 `'X'` 都会在这一轮被处理完毕。将答案加 1，下标直接跳过 3 格（等价于这三格已全部“消化”）。

正确性：若下标 `i` 处为 `'X'` 且尚未被之前的操作覆盖，则必须以 `i` 为起点（或包含 `i` 的某段长度为 3 的窗口）进行操作；贪心地在 `i` 处立即执行一次操作，可尽早消除该 `'X'`，且不会使总次数变多。重复上述过程直至扫描结束。

时间复杂度与字符串长度成正比，额外空间为常数级。

## 解法

```java
class Solution {
    public int minimumMoves(String s) {
        int ans = 0;
        for (int i = 0; i < s.length(); ++i) {
            if (s.charAt(i) == 'X') {
                ++ans;
                i += 2;
            }
        }
        return ans;
    }
}
```

## 总结

- 贪心：遇到 `'X'` 就执行一次操作，并跳过连续三个字符。
- 一次操作覆盖的窗口长度为 3，已覆盖的 `'X'` 不必再单独计数。
- 实现时注意 for 循环中 `i += 2` 与循环末尾自增结合，等价于下标前进 3 格。
