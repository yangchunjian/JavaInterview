## 题目

给你一个字符串 `s`，一个整数 `k`，一个字母 `letter` 以及另一个整数 `repetition`。

返回 `s` 中长度为 `k` 且**字典序最小**的子序列，该子序列同时应满足字母 `letter` 出现**至少** `repetition` 次。生成的测试用例保证 `letter` 在 `s` 中出现至少 `repetition` 次。

**子序列**是由原字符串删除一些（或不删除）字符且不改变剩余字符顺序得到的剩余字符串。

字符串 `a` 字典序比字符串 `b` 小的定义为：在 `a` 和 `b` 出现不同字符的第一个位置上，字符串 `a` 的字符在字母表中的顺序早于字符串 `b` 的字符。

### 示例 1

| 项目 | 内容 |
| --- | --- |
| **输入** | `s = "leet"`, `k = 3`, `letter = "e"`, `repetition = 1` |
| **输出** | `"eet"` |
| **解释** | 长度为 3 且字母 `e` 至少出现 1 次的子序列有 `"lee"`、`"let"`、`"let"`、`"eet"`，其中字典序最小的是 `"eet"`。 |

### 示例 2

| 项目 | 内容 |
| --- | --- |
| **输入** | `s = "leetcode"`, `k = 4`, `letter = "e"`, `repetition = 2` |
| **输出** | `"ecde"` |
| **解释** | `"ecde"` 是长度为 4 且字母 `e` 至少出现 2 次的字典序最小子序列。 |

### 示例 3

| 项目 | 内容 |
| --- | --- |
| **输入** | `s = "bb"`, `k = 2`, `letter = "b"`, `repetition = 2` |
| **输出** | `"bb"` |
| **解释** | `"bb"` 是唯一满足条件的长度为 2 的子序列。 |

### 提示

- `1 <= repetition <= k <= s.length <= 5 * 10^4`
- `s` 由小写英文字母组成
- `letter` 是小写英文字母，在 `s` 中至少出现 `repetition` 次

## 思路

本题是「移掉 K 位数字」「去除重复字母」一类**单调栈**问题的进阶：在最多删除 `len(s) - k` 个字符的前提下，从 `s` 中选出长度为 `k` 的字典序最小子序列，且其中字母 `letter` 至少出现 `repetition` 次。

**第一步：统计与变量**

- `delete`：最多还能删除的字符个数，等于 `s.length() - k`。
- `remain`：最终子序列长度，等于 `k`。
- `preLetters`：当前栈中 `letter` 的个数。
- `posLetters`：`s` 中尚未遍历部分（含当前字符）里 `letter` 还能提供的个数；每遇到一个 `letter` 就减 1。

**第二步：单调栈贪心（主循环）**

从左到右扫描 `s`。若栈非空、栈顶字符字典序大于当前字符、且 `delete` 仍大于 0，则尝试弹出栈顶以变小字典序。

弹出栈顶时需额外判断：

- 若栈顶是 `letter`，弹出后栈内 `letter` 会减少。若「栈内已有个数减 1」再加上「后面还能提供的个数」仍达不到 `repetition`，则**不能弹出**，应停止本轮弹出。
- 等价条件：当 `repetition` 大于 `preLetters + posLetters - 1` 时，禁止弹出栈顶的 `letter`。

每弹出一个字符，`delete` 减 1；若弹出的是 `letter`，`preLetters` 减 1。将当前字符入栈后，若当前字符是 `letter`，则 `preLetters` 加 1，`posLetters` 减 1。

**第三步：截断到长度 k**

主循环结束后栈长度可能大于 `remain`。从栈尾继续弹出直到长度为 `remain`，弹出 `letter` 时同步减少 `preLetters`。

**第四步：补足 repetition**

截断后若栈中 `letter` 仍不足 `repetition`，从结果末尾向前，将非 `letter` 的字符替换为 `letter`，直到 `preLetters` 达到 `repetition`。这样在不改变长度的前提下尽量满足次数约束（替换靠后的非目标字母对字典序影响最小）。

时间复杂度 O(n)，额外空间 O(n)，其中 n 为 `s` 的长度。

## 解法

```java
class Solution {
    public String smallestSubsequence(String s, int k, char letter, int repetition) {
        Deque<Character> stack = new ArrayDeque<>();
        int remain = k;
        int delete = s.length() - k;
        int preLetters = 0;
        int posLetters = 0;
        for (char c : s.toCharArray()) {
            if (c == letter) {
                posLetters++;
            }
        }
        for (char a : s.toCharArray()) {
            while (delete > 0 && !stack.isEmpty() && stack.peekLast() > a) {
                if (stack.peekLast() == letter) {
                    if (repetition > preLetters + posLetters - 1) {
                        break;
                    }
                    preLetters--;
                }
                stack.removeLast();
                delete--;
            }
            if (a == letter) {
                preLetters++;
                posLetters--;
            }
            stack.addLast(a);
        }
        while (stack.size() > remain) {
            if (stack.peekLast() == letter) {
                preLetters--;
            }
            stack.removeLast();
        }
        char[] arr = new char[remain];
        int idx = 0;
        for (char c : stack) {
            arr[idx++] = c;
        }
        for (int i = remain - 1; i >= 0 && preLetters < repetition; i--) {
            if (arr[i] != letter) {
                arr[i] = letter;
                preLetters++;
            }
        }
        return new String(arr);
    }
}
```

## 总结

- 在最多删除 `s.length() - k` 个字符的限制下，用单调栈维护字典序最小的候选子序列。
- 弹出栈顶 `letter` 前必须保证：弹出后即使把后面所有 `letter` 都选上，仍能达到 `repetition` 次。
- 截断到长度 `k` 后，若 `letter` 仍不足，从尾部向前把非 `letter` 替换为 `letter` 以满足次数要求。
