## 题目

你的任务是为一个很受欢迎的银行设计一款程序，以自动化执行所有传入的交易（转账，存款和取款）。银行共有 `n` 个账户，编号从 `1` 到 `n` 。每个账号的初始余额存储在一个下标从 **0** 开始的整数数组 `balance` 中，其中第 `(i + 1)` 个账户的初始余额是 `balance[i]` 。

请你执行所有 **有效的** 交易。如果满足下面全部条件，则交易 **有效** ：

- 指定的账户编号在 `1` 和 `n` 之间，且
- 取款或者转账需要的钱的总数 **小于或者等于** 账户余额。

实现 `Bank` 类：

- `Bank(long[] balance)` 使用下标从 **0** 开始的整数数组 `balance` 初始化该对象。
- `boolean transfer(int account1, int account2, long money)` 从编号为 `account1` 的账户向编号为 `account2` 的账户转帐 `money` 美元。如果交易成功，返回 `true` ，否则，返回 `false` 。
- `boolean deposit(int account, long money)` 向编号为 `account` 的账户存款 `money` 美元。如果交易成功，返回 `true` ；否则，返回 `false` 。
- `boolean withdraw(int account, long money)` 从编号为 `account` 的账户取款 `money` 美元。如果交易成功，返回 `true` ；否则，返回 `false` 。

### 示例

| 项目 | 内容 |
| --- | --- |
| **输入** | 操作序列 `["Bank", "withdraw", "transfer", "deposit", "transfer", "withdraw"]`，参数 `[[[10, 100, 20, 50, 30]], [3, 10], [5, 1, 20], [5, 20], [3, 4, 15], [10, 50]]` |
| **输出** | `[null, true, true, true, false, false]` |

**解释：**

```text
Bank bank = new Bank([10, 100, 20, 50, 30]);
bank.withdraw(3, 10);    // 返回 true ，账户 3 的余额是 20 ，所以可以取款 10 。
                         // 账户 3 余额为 20 - 10 = 10 。
bank.transfer(5, 1, 20); // 返回 true ，账户 5 的余额是 30 ，所以可以转账 20 。
                         // 账户 5 的余额为 30 - 20 = 10 ，账户 1 的余额为 10 + 20 = 30 。
bank.deposit(5, 20);     // 返回 true ，可以向账户 5 存款 20 。
                         // 账户 5 的余额为 10 + 20 = 30 。
bank.transfer(3, 4, 15); // 返回 false ，账户 3 的当前余额是 10 。
                         // 所以无法转账 15 。
bank.withdraw(10, 50);   // 返回 false ，交易无效，因为账户 10 并不存在。
```

### 提示

- `n == balance.length`
- `1 <= n, account, account1, account2 <= 10^5`
- `0 <= balance[i], money <= 10^12`
- `transfer`、`deposit`、`withdraw` 三个函数，**每个** 最多调用 `10^4` 次

## 思路

本题是银行账户的模拟。银行有 `n` 个账户，编号从 1 到 `n`，初始余额放在下标从 0 开始的数组 `balance` 里，因此编号为 `account` 的账户对应下标 `account - 1`。

每次交易先判断是否有效：账户编号必须落在 1 到 `n` 之间；取款和转账还要求当前余额不少于操作金额。存款只需编号合法。余额和金额最大可达 10 的 12 次方，因此余额数组用 `long` 保存，加减时不要用 `int`。

实现时把 `balance` 保存在类中即可。`withdraw` 先校验编号和余额，再从对应下标减去金额。`deposit` 校验编号后加上金额。`transfer` 需要同时校验两个账户，并从转出账户扣款、向转入账户加款；任一条件不满足就返回 `false`，且不修改任何余额。三个操作各自最多调用 1 万次，每次都是常数时间，足以通过。

## 解法

```java
class Bank {
    private long[] balance;

    public Bank(long[] balance) {
        this.balance = balance;
    }

    public boolean transfer(int account1, int account2, long money) {
        if (!valid(account1) || !valid(account2) || balance[account1 - 1] < money) {
            return false;
        }
        balance[account1 - 1] -= money;
        balance[account2 - 1] += money;
        return true;
    }

    public boolean deposit(int account, long money) {
        if (!valid(account)) {
            return false;
        }
        balance[account - 1] += money;
        return true;
    }

    public boolean withdraw(int account, long money) {
        if (!valid(account) || balance[account - 1] < money) {
            return false;
        }
        balance[account - 1] -= money;
        return true;
    }

    private boolean valid(int account) {
        return account >= 1 && account <= balance.length;
    }
}
```

## 总结

- 账户编号从 1 开始，访问余额时用 `account - 1` 作为数组下标。
- 交易前必须校验编号范围；取款和转账还要校验余额是否足够，失败时不要改余额。
- 余额与金额上限为 10 的 12 次方，使用 `long` 避免溢出。
