## 题目

现有一份 **n + m** 次投掷单个 **六面** 骰子的观测数据，骰子的每个面从 **1** 到 **6** 编号。观测数据中缺失了 **n** 份，你手上只拿到剩余 **m** 次投掷的数据。幸好你有之前计算过的这 **n + m** 次投掷数据的 **平均值**。

给你一个长度为 **m** 的整数数组 `rolls`，其中 `rolls[i]` 是第 **i** 次观测的值。同时给你两个整数 `mean` 和 `n`。

返回一个长度为 **n** 的数组，包含所有缺失的观测数据，且满足这 **n + m** 次投掷的 **平均值** 是 `mean`。如果存在多组符合要求的答案，只需要返回其中任意一组即可。如果不存在答案，返回一个空数组。

**k** 个数字的 **平均值** 为这些数字求和后再除以 **k**。

注意 `mean` 是一个整数，所以 **n + m** 次投掷的总和需要被 **n + m** 整除。

### 示例 1

| 项目 | 内容 |
| --- | --- |
| **输入** | `rolls = [3,2,4,3]`, `mean = 4`, `n = 2` |
| **输出** | `[6,6]` |
| **解释** | 所有 n + m 次投掷的平均值是 (3 + 2 + 4 + 3 + 6 + 6) / 6 = 4。 |

### 示例 2

| 项目 | 内容 |
| --- | --- |
| **输入** | `rolls = [1,5,6]`, `mean = 3`, `n = 4` |
| **输出** | `[2,3,2,2]` |
| **解释** | 所有 n + m 次投掷的平均值是 (1 + 5 + 6 + 2 + 3 + 2 + 2) / 7 = 3。 |

### 示例 3

| 项目 | 内容 |
| --- | --- |
| **输入** | `rolls = [1,2,3,4]`, `mean = 6`, `n = 4` |
| **输出** | `[]` |
| **解释** | 无论丢失的 4 次数据是什么，平均值都不可能是 6。 |

### 示例 4

| 项目 | 内容 |
| --- | --- |
| **输入** | `rolls = [1]`, `mean = 3`, `n = 1` |
| **输出** | `[5]` |
| **解释** | 所有 n + m 次投掷的平均值是 (1 + 5) / 2 = 3。 |

### 提示

- `m == rolls.length`
- `1 <= n, m <= 10^5`
- `1 <= rolls[i], mean <= 6`

## 思路

设已知投掷次数为 `m`，缺失次数为 `n`。

**第一步：计算缺失观测的总和**

全部 **n + m** 次投掷的总和为 `(n + m) * mean`。减去 `rolls` 中已有观测之和，得到缺失的 **n** 个数的总和，记为 `s`：

`s = (n + m) * mean - sum(rolls)`

**第二步：判断是否存在合法解**

每个骰子点数在 **1** 到 **6** 之间，因此 **n** 个缺失数的总和必须满足：`n <= s <= n * 6`。若不满足，返回空数组。

**第三步：构造一组答案**

在合法前提下，将 `s` 尽量均匀地分给 **n** 个数：

- 每个数先取 `s / n`（整除）；
- 前 `s % n` 个数各再加 **1**。

这样得到的每个数仍在 **1** 到 **6** 之间，且总和恰好为 `s`，平均值即为 `mean`。题目允许多组答案，上述构造即可。

时间复杂度与 `n + m` 成正比，额外空间为常数级（不计输出数组）。

## 解法

```java
class Solution {
    public int[] missingRolls(int[] rolls, int mean, int n) {
        int m = rolls.length;
        int s = (n + m) * mean;
        for (int v : rolls) {
            s -= v;
        }
        if (s > n * 6 || s < n) {
            return new int[0];
        }
        int[] ans = new int[n];
        Arrays.fill(ans, s / n);
        for (int i = 0; i < s % n; ++i) {
            ++ans[i];
        }
        return ans;
    }
}
```

## 总结

- 先算缺失观测总和 `s`，再用 `n <= s <= 6n` 判断是否有解。
- 构造法：均分 `s / n`，余数 `s % n` 依次加在靠前的位置上。
- 单骰点数上界为 6，下界为 1，是可行性的核心约束。
