## 题目

给你一支股票价格的数据流。数据流中每一条记录包含一个 **时间戳** 和该时间点股票对应的 **价格**。

不巧的是，由于股票市场内在的波动性，股票价格记录可能不是按时间顺序到来的。某些情况下，有的记录可能是错的。如果两个有相同时间戳的记录出现在数据流中，前一条记录视为错误记录，后出现的记录 **更正** 前一条错误的记录。

请你设计一个算法，实现：

- **更新** 股票在某一时间戳的股票价格，如果有之前同一时间戳的价格，这一操作将 **更正** 之前的错误价格。
- 找到当前记录里 **最新股票价格**。**最新股票价格** 定义为时间戳最晚的股票价格。
- 找到当前记录里股票的 **最高价格**。
- 找到当前记录里股票的 **最低价格**。

请你实现 `StockPrice` 类：

- `StockPrice()` 初始化对象，当前无股票价格记录。
- `void update(int timestamp, int price)` 在时间点 `timestamp` 更新股票价格为 `price`。
- `int current()` 返回股票 **最新价格**。
- `int maximum()` 返回股票 **最高价格**。
- `int minimum()` 返回股票 **最低价格**。

### 示例 1

| 项目 | 内容 |
| --- | --- |
| **输入** | 操作序列 `["StockPrice", "update", "update", "current", "maximum", "update", "maximum", "update", "minimum"]`，参数 `[[], [1, 10], [2, 5], [], [], [1, 3], [], [4, 2], []]` |
| **输出** | `[null, null, null, 5, 10, null, 5, null, 2]` |

**解释：**

```text
StockPrice stockPrice = new StockPrice();
stockPrice.update(1, 10); // 时间戳为 [1]，对应的股票价格为 [10]。
stockPrice.update(2, 5);  // 时间戳为 [1, 2]，对应的股票价格为 [10, 5]。
stockPrice.current();     // 返回 5，最新时间戳为 2，对应价格为 5。
stockPrice.maximum();     // 返回 10，最高价格的时间戳为 1，价格为 10。
stockPrice.update(1, 3);  // 之前时间戳为 1 的价格错误，价格更新为 3。
                          // 时间戳为 [1, 2]，对应股票价格为 [3, 5]。
stockPrice.maximum();     // 返回 5，更正后最高价格为 5。
stockPrice.update(4, 2);  // 时间戳为 [1, 2, 4]，对应价格为 [3, 5, 2]。
stockPrice.minimum();     // 返回 2，最低价格时间戳为 4，价格为 2。
```

### 提示

- `1 <= timestamp, price <= 10^9`
- `update`、`current`、`maximum` 和 `minimum` **总** 调用次数不超过 `10^5`。
- `current`、`maximum` 和 `minimum` 被调用时，`update` 操作 **至少** 已经被调用过 **一次**。

## 思路

本题需要在数据流上同时支持：按时间戳写入或更正价格、查询时间戳最大的那条价格、以及查询当前所有有效价格中的最大值和最小值。总调用次数上限为 10 的 5 次方，因此每次操作需要接近对数级时间。

用哈希表 `timeToPrice` 保存「时间戳到当前价格」的映射。同一时间戳再次 `update` 时，直接覆盖旧价格即可，这样哈希表里始终只有有效记录。再单独用变量 `latestTime` 记录目前出现过的最大时间戳，`current` 就是查这个时间戳对应的价格。

最值不能只扫一遍哈希表，否则会超时。用有序映射 `priceCount` 维护「价格到出现次数」。`TreeMap` 按价格从小到大排列，`firstKey` 是当前最低价，`lastKey` 是当前最高价。

`update` 时分两步：

1. 若该时间戳已有旧价格，把旧价格的出现次数减 1；减到 0 时从有序映射中删除该价格，避免失效价格继续影响最值。
2. 写入新价格，并把新价格的出现次数加 1；同时用 `Math.max` 更新 `latestTime`。

这样更正操作只会替换同一时间戳上的那一个价格，不会把历史错误价格留在最值结构里。时间复杂度上，哈希表操作为常数级，有序映射每次插入删除为对数级；空间与当前不同时间戳数量成正比。

## 解法

```java
class StockPrice {
    private Map<Integer, Integer> timeToPrice;
    private TreeMap<Integer, Integer> priceCount;
    private int latestTime;

    public StockPrice() {
        timeToPrice = new HashMap<>();
        priceCount = new TreeMap<>();
        latestTime = 0;
    }

    public void update(int timestamp, int price) {
        if (timeToPrice.containsKey(timestamp)) {
            int oldPrice = timeToPrice.get(timestamp);
            int count = priceCount.get(oldPrice);
            if (count == 1) {
                priceCount.remove(oldPrice);
            } else {
                priceCount.put(oldPrice, count - 1);
            }
        }
        timeToPrice.put(timestamp, price);
        priceCount.put(price, priceCount.getOrDefault(price, 0) + 1);
        latestTime = Math.max(latestTime, timestamp);
    }

    public int current() {
        return timeToPrice.get(latestTime);
    }

    public int maximum() {
        return priceCount.lastKey();
    }

    public int minimum() {
        return priceCount.firstKey();
    }
}
```

## 总结

- 哈希表保证每个时间戳只保留最新一次价格，用于更正和查询当前价。
- 有序映射统计价格出现次数，支持在更正后仍正确得到最高价和最低价。
- 更正时必须先把旧价格的计数减掉，计数为 0 时删除该键，否则最值会被脏数据污染。
