## 题目

给你一个长度为 `2 * n` 的整数数组 `nums`。你需要将 `nums` 分成 **两个** 长度为 `n` 的数组，分别求出两个数组的和，并 **最小化** 两个数组和之 **差的绝对值**。`nums` 中每个元素都需要放入两个数组之一。

请你返回 **最小** 的数组和之差。

### 示例 1

![2035 示例 1](../../../media/pictures/leetcode/2035-ex1.png)

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums = [3,9,7,3]` |
| **输出** | `2` |

**解释：** 最优分组方案是分成 `[3,9]` 和 `[7,3]`。数组和之差的绝对值为 `abs((3 + 9) - (7 + 3)) = 2`。

### 示例 2

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums = [-36,36]` |
| **输出** | `72` |

**解释：** 最优分组方案是分成 `[-36]` 和 `[36]`。数组和之差的绝对值为 `abs((-36) - (36)) = 72`。

### 示例 3

![2035 示例 3](../../../media/pictures/leetcode/2035-ex3.png)

| 项目 | 内容 |
| --- | --- |
| **输入** | `nums = [2,-1,0,4,-2,-9]` |
| **输出** | `0` |

**解释：** 最优分组方案是分成 `[2,4,-9]` 和 `[-1,0,-2]`。数组和之差的绝对值为 `abs((2 + 4 + -9) - (-1 + 0 + -2)) = 0`。

### 提示

- `1 <= n <= 15`
- `nums.length == 2 * n`
- `-10^7 <= nums[i] <= 10^7`

## 思路

设数组长度为 `2n`，总元素和为 `total`。从中选出恰好 `n` 个数组成第一组，其和记为 `s`，则第二组和为 `total - s`，两组和的绝对差等于 `abs(total - 2 * s)`。因此问题转化为：选出恰好 `n` 个数，使它们的和尽可能接近 `total` 的一半。

`n` 最大为 15，对全部 `2n` 个位置做子集枚举是 2 的 30 次方量级，会超时。把数组从中间切开，左半、右半各 `n` 个元素。对每一半枚举全部子集（2 的 15 次方约 3 万），并按「选了多少个元素」分组，得到：左半选出 `k` 个数的所有可能和，以及右半选出 `n - k` 个数的所有可能和。

第一组的 `n` 个数一定来自「左半选 `k` 个」加上「右半选 `n - k` 个」，`k` 从 0 取到 `n`。对每个 `k`，把右半对应的和数组排序。遍历左半的每个和 `a`，在右半中二分查找最接近 `total / 2 - a` 的值 `b`，用 `abs(total - 2 * (a + b))` 更新答案。相邻两个候选都要检查，以免错过更接近的一侧。

时间上，每一半枚举约 3 万种子集；对每个 `k` 排序后再对左半每个和做对数级查找，总体可以在时限内完成。空间与子集个数同阶。

## 解法

```java
class Solution {
    public int minimumDifference(int[] nums) {
        int n = nums.length / 2;
        int total = 0;
        for (int x : nums) {
            total += x;
        }
        List<Integer>[] left = subsetSums(nums, 0, n);
        List<Integer>[] right = subsetSums(nums, n, n);
        int ans = Integer.MAX_VALUE;
        for (int k = 0; k <= n; k++) {
            int[] r = toSortedArray(right[n - k]);
            for (int a : left[k]) {
                int need = total / 2 - a;
                int idx = lowerBound(r, need);
                if (idx < r.length) {
                    ans = Math.min(ans, Math.abs(total - 2 * (a + r[idx])));
                }
                if (idx > 0) {
                    ans = Math.min(ans, Math.abs(total - 2 * (a + r[idx - 1])));
                }
                if (ans == 0) {
                    return 0;
                }
            }
        }
        return ans;
    }

    private List<Integer>[] subsetSums(int[] nums, int start, int n) {
        List<Integer>[] sums = new List[n + 1];
        for (int i = 0; i <= n; i++) {
            sums[i] = new ArrayList<>();
        }
        int limit = 1 << n;
        for (int mask = 0; mask < limit; mask++) {
            int sum = 0;
            int cnt = 0;
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {
                    sum += nums[start + i];
                    cnt++;
                }
            }
            sums[cnt].add(sum);
        }
        return sums;
    }

    private int[] toSortedArray(List<Integer> list) {
        int[] arr = new int[list.size()];
        for (int i = 0; i < arr.length; i++) {
            arr[i] = list.get(i);
        }
        Arrays.sort(arr);
        return arr;
    }

    private int lowerBound(int[] arr, int target) {
        int l = 0;
        int r = arr.length;
        while (l < r) {
            int mid = (l + r) >>> 1;
            if (arr[mid] < target) {
                l = mid + 1;
            } else {
                r = mid;
            }
        }
        return l;
    }
}
```

## 总结

- 两组等长划分的最小绝对差，等价于选出 `n` 个数使其和尽量接近总和的一半。
- `n` 最大为 15，对整段做子集枚举不可行，需把数组对半切开再分别枚举。
- 按选出的个数分组后，左半一个和对应右半一次二分，检查插入位置及其前驱即可。
- 差为 0 时可以提前返回。
