## 题目

总共有 `n` 个颜色片段排成一列，每个颜色片段要么是 `'A'` 要么是 `'B'`。给你一个长度为 `n` 的字符串 `colors`，其中 `colors[i]` 表示第 `i` 个颜色片段的颜色。

Alice 和 Bob 在玩一个游戏，他们 **轮流** 从这个字符串中删除颜色。Alice **先手**。

- 如果一个颜色片段为 `'A'` 且 **相邻两个颜色** 都是颜色 `'A'`，那么 Alice 可以删除该颜色片段。Alice **不可以** 删除任何颜色 `'B'` 片段。
- 如果一个颜色片段为 `'B'` 且 **相邻两个颜色** 都是颜色 `'B'`，那么 Bob 可以删除该颜色片段。Bob **不可以** 删除任何颜色 `'A'` 片段。
- Alice 和 Bob **不能** 从字符串两端删除颜色片段。
- 如果其中一人无法继续操作，则该玩家 **输** 掉游戏且另一玩家 **获胜**。

假设 Alice 和 Bob 都采用最优策略，如果 Alice 获胜，请返回 `true`，否则 Bob 获胜，返回 `false`。

### 示例 1

| 项目 | 内容 |
| --- | --- |
| **输入** | `colors = "AAABABB"` |
| **输出** | `true` |

**解释：**

`AAABABB` 中 Alice 先操作，删除从左数第二个 `'A'`（这也是唯一一个相邻颜色片段都是 `'A'` 的 `'A'`），变成 `AABABB`。

现在轮到 Bob。没有相邻位置都是 `'B'` 的颜色片段 `'B'`，Bob 无法操作。因此 Alice 获胜，返回 `true`。

### 示例 2

| 项目 | 内容 |
| --- | --- |
| **输入** | `colors = "AA"` |
| **输出** | `false` |

**解释：** Alice 先操作。只有 2 个 `'A'` 且它们都在字符串的两端，所以她无法执行任何操作。因此 Bob 获胜，返回 `false`。

### 示例 3

| 项目 | 内容 |
| --- | --- |
| **输入** | `colors = "ABBBBBBBAAA"` |
| **输出** | `false` |

**解释：**

Alice 先操作，唯一的选择是删除从右数起第二个 `'A'`，变成 `ABBBBBBBAA`。

接下来 Bob 可以删除某个 `'B'`。之后再轮到 Alice 时，她无法删除任何片段。所以 Bob 获胜，返回 `false`。

### 提示

- `1 <= colors.length <= 10^5`
- `colors` 只包含字母 `'A'` 和 `'B'`

## 思路

看起来像博弈，其实双方的可操作次数互不影响。Alice 只能删 `'A'`，Bob 只能删 `'B'`。删掉一段连续同色里的中间字符后，该段长度减 1，两端字符仍然把对方颜色隔开，不会把对方的两段拼到一起，也不会给对方多出新的可删位置。因此一方怎么走，都不会改变另一方总共能走几步。

一段长度为 `k` 的连续同色，两端字符的邻居不可能都是这种颜色，中间一共有 `k - 2` 个位置满足「左右邻居颜色相同」。每删掉其中一个，该段还剩 `k - 1` 个，可删位置变成 `k - 3`，如此直到只剩 2 个。所以这段能贡献的操作次数就是 `max(k - 2, 0)`。

把整串按连续段扫描，把 `'A'` 段的可操作次数加给 Alice，`'B'` 段的加给 Bob。Alice 先手，她获胜当且仅当她的次数严格大于 Bob。次数相等时轮到 Alice 却没步可走，Bob 胜。

实现上也可以直接扫下标 1 到 n 减 2：若 `colors[i - 1]`、`colors[i]`、`colors[i + 1]` 三者相同，就把该颜色的计数加 1。这与按段统计 `k - 2` 等价。长度最大 10 的 5 次方，一次线性扫描即可。

## 解法

```java
class Solution {
    public boolean winnerOfGame(String colors) {
        int alice = 0;
        int bob = 0;
        int n = colors.length();
        for (int i = 1; i < n - 1; i++) {
            char c = colors.charAt(i);
            if (c == colors.charAt(i - 1) && c == colors.charAt(i + 1)) {
                if (c == 'A') {
                    alice++;
                } else {
                    bob++;
                }
            }
        }
        return alice > bob;
    }
}
```

## 总结

- 删自己颜色不会合并对方的连续段，双方步数独立，不必模拟回合。
- 长度为 `k` 的连续同色最多操作 `k - 2` 次（`k` 小于 3 则为 0）。
- Alice 获胜条件是其可操作次数严格大于 Bob；相等时先手无步可走则负。
- 线性扫描三连相同字符即可，时间与字符串长度成正比。
