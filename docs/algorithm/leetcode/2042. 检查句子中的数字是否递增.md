## 题目

句子是由若干 **token** 组成的一个列表，**token** 间用 **单个** 空格分隔，句子没有前导或尾随空格。每个 token 要么是一个由数字 `0-9` 组成的不含前导零的 **正整数**，要么是一个由小写英文字母组成的 **单词**。

- 示例，`"a puppy has 2 eyes 4 legs"` 是一个由 7 个 token 组成的句子：`"2"` 和 `"4"` 是数字，其他像 `"puppy"` 这样的 token 属于单词。

给你一个表示句子的字符串 `s`，你需要检查 `s` 中的 **全部** 数字是否从左到右严格递增（即，除了最后一个数字，`s` 中的 **每个** 数字都严格小于它 **右侧** 的数字）。

如果满足题目要求，返回 `true`，否则，返回 `false`。

### 提示

- `3 <= s.length <= 200`
- `s` 由小写英文字母、空格和数字 `0` 到 `9` 组成（包含 `0` 和 `9`）
- `s` 中数字 token 的数目在 `2` 和 `100` 之间（包含 `2` 和 `100`）
- `s` 中的 token 之间由单个空格分隔
- `s` 中至少有 **两个** 数字
- `s` 中的每个数字都是一个 **小于** `100` 的 **正** 数，且不含前导零
- `s` 不含前导或尾随空格

## 思路

题目保证 token 只可能是不含前导零的正整数，或纯小写字母单词，并且用单个空格隔开。因此只需按空格切开，从左到右扫描，遇到数字就和上一个数字比较。

维护上一个数字 `pre`。因为所有数字都是正数，可以把 `pre` 初始化为 `0`，这样第一个数字一定比它大。对每个 token：若首字符是数字，则解析成整数 `cur`；若 `cur` 小于等于 `pre`，说明没有严格递增，立刻返回 `false`；否则把 `pre` 更新为 `cur`。全部扫完仍未失败，则返回 `true`。

判断是否为数字时，看首字符是否为 `'0'` 到 `'9'` 即可。单词全是小写字母，不会以数字开头，也不存在把单词误判成数字的情况。数字本身不含前导零，直接 `Integer.parseInt` 即可。

时间复杂度与字符串长度成线性关系，空间主要来自分割后的 token 数组。也可以不分割、逐字符累加当前数字，在遇到空格时结算一次，空间可以降到常数，但对本题长度上限 200 来说没有必要。

## 解法

```java
class Solution {
    public boolean areNumbersAscending(String s) {
        int pre = 0;
        for (String t : s.split(" ")) {
            if (t.charAt(0) >= '0' && t.charAt(0) <= '9') {
                int cur = Integer.parseInt(t);
                if (cur <= pre) {
                    return false;
                }
                pre = cur;
            }
        }
        return true;
    }
}
```

## 总结

- 按空格拆分后，只对数字 token 做严格递增检查。
- 用上一个数字 `pre` 与当前数字比较，出现小于等于关系即失败。
- 数字为正且无前导零，首字符是数字即可认定该 token 为数字。
