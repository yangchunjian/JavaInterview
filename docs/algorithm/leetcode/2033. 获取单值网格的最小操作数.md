## 题目

给你一个大小为 `m x n` 的二维整数网格 `grid` 和一个整数 `x`。每一次操作，你可以对 `grid` 中的任一元素 **加** `x` 或 **减** `x`。

**单值网格** 是全部元素都相等的网格。

返回使网格化为单值网格所需的 **最小** 操作数。如果不能，返回 `-1`。

### 示例 1

| 项目 | 内容 |
| --- | --- |
| **输入** | `grid = [[2,4],[6,8]]`, `x = 2` |
| **输出** | `4` |
| **解释** | 可以执行下述操作使所有元素都等于 4：2 加 x 一次；6 减 x 一次；8 减 x 两次。共计 4 次操作。 |

### 示例 2

| 项目 | 内容 |
| --- | --- |
| **输入** | `grid = [[1,5],[2,3]]`, `x = 1` |
| **输出** | `5` |
| **解释** | 可以使所有元素都等于 3。 |

### 示例 3

| 项目 | 内容 |
| --- | --- |
| **输入** | `grid = [[1,2],[3,4]]`, `x = 2` |
| **输出** | `-1` |
| **解释** | 无法使所有元素相等。 |

### 提示

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 10^5`
- `1 <= m * n <= 10^5`
- `1 <= x, grid[i][j] <= 10^4`

## 思路

本题每次只能把某个格子加 `x` 或减 `x`，因此任意格子经过若干次操作后，其值与初始值对 `x` 的余数始终不变。

**第一步：余数一致性**

遍历整个网格，记录 `grid[0][0] % x` 作为目标余数 `mod`。若存在某个元素 `grid[i][j] % x` 与 `mod` 不同，说明无论如何操作都无法让所有格子相等，直接返回 `-1`。

**第二步：展平并排序**

将所有元素放入一维数组 `nums`，排序后取中位数 `mid` 作为最终统一的目标值。在只能按步长 `x` 移动的前提下，要使「把每个数变到同一目标值」所需的总步数最少，应选中位数（与「使绝对偏差之和最小」的经典结论一致）。

**第三步：累加操作次数**

对每个元素 `v`，需要 `Math.abs(v - mid) / x` 次操作（差值必为 `x` 的整数倍）。将全部次数相加即为答案。

时间复杂度 O(m * n * log(m * n))，空间复杂度 O(m * n)，其中 m、n 为网格行数与列数。

## 解法

```java
class Solution {
    public int minOperations(int[][] grid, int x) {
        int m = grid.length, n = grid[0].length;
        int[] nums = new int[m * n];
        int mod = grid[0][0] % x;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] % x != mod) {
                    return -1;
                }
                nums[i * n + j] = grid[i][j];
            }
        }
        Arrays.sort(nums);
        int mid = nums[nums.length >> 1];
        int ans = 0;
        for (int v : nums) {
            ans += Math.abs(v - mid) / x;
        }
        return ans;
    }
}
```

## 总结

- 每次加减 `x` 不改变元素对 `x` 的余数，因此所有格子必须余数相同才可能化为单值网格。
- 余数校验通过后，将网格展平排序，以中位数为目标可最小化总操作次数。
- 单个元素所需次数为与目标值的差除以 `x`，全部累加即得最小操作数。
